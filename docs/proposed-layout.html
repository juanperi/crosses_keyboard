Review markers: amber labels are unresolved proposals. The Win layer preserves the UHK letter positions, but its exact macOS actions still need to be confirmed from the UHK behavior.
Base access

Home-row mods: A/Ctrl, S/Option, D/Shift, F/Command; mirrored on J/Command, K/Shift, L/Option, and semicolon/Ctrl.

Layer philosophy

Nav + Win is one left-thumb layer for arrows, document movement, and UHK window controls. Num combines numbers with trackball clicks. Sym remains separate. Bluetooth and recovery controls live on Sys.

UHK migration

Nav + Win preserves the UHK actions on QWERTY positions: W/R tabs, E Mission Control, S/F spaces (Ctrl+Option+Left/Right), D Alt+Tab, and X/V Slack conversations. Command remains on the F home-row hold. Screenshot uses Cmd+Ctrl+Shift+4 to copy a selected region to the clipboard.

Safety

Hold the Base Num and Sym/Backspace thumbs together to access Sys. Bootloader is available on both sides in the second row: left outer key for the left half, right outer key for the right half.
